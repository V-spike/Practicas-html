Ejercicio 7.12

¿Algún cliente excedió su límite de crédito?

Para cada cliente se piden: número de cuenta, saldo inicial, cargos del mes, créditos del mes y límite de crédito. Se calcula nuevo saldo = saldo inicial + cargos - créditos. Si el nuevo saldo es mayor que el límite, se muestra "Se excedió el límite de su crédito". El centinela es el número de cuenta -1.

Pseudocódigo

Cima: Determinar qué clientes excedieron su límite de crédito.

Pedir el número de cuenta (o -1 para terminar)
Mientras número de cuenta sea distinto de -1
    Pedir saldo inicial, cargos, créditos y límite de crédito
    nuevoSaldo = saldo inicial + cargos - créditos
    Mostrar número de cuenta y nuevoSaldo
    Si nuevoSaldo es mayor que el límite
        Mostrar "Se excedió el límite de su crédito"
    Pedir el siguiente número de cuenta (o -1 para terminar)

Resultados

Datos de prueba sugeridos (3 conjuntos):

  • Cuenta 100: saldo 5000, cargos 2000, créditos 500, límite 6000. Nuevo saldo 6500, excede.
  • Cuenta 200: saldo 1000, cargos 300, créditos 800, límite 2000. Nuevo saldo 500, no excede.
  • Cuenta 300: saldo 3000, cargos 1000, créditos 0, límite 4000. Nuevo saldo 4000, no excede (es igual, no mayor).
