Ejercicio 7.10

Sin ejecutarla, determine lo que imprime esta secuencia de comandos

var y;
var x = 1;
var total = 0;

while ( x <= 10 )
{
   y = x * x;
   document.writeln( "<p>" + y + "</p>" );
   total += y;
   ++x;
} // fin de while

document.writeln( "<p>El total es " + total + "</p>" );

Análisis (prueba de escritorio)

El ciclo va de x = 1 a x = 10. En cada vuelta calcula el cuadrado de x, lo imprime y lo acumula. Imprime en párrafos separados: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100. Al final imprime "El total es 385" (la suma de los cuadrados del 1 al 10).
