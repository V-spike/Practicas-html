Ejercicio 7.07

Identifique y corrija los errores en cada segmento de código

  1. while ( c <= 5 ) {
   producto *= c;
   ++c;
    Error: falta la llave derecha } que cierra el cuerpo del while.
    Corrección: 
    while ( c <= 5 ) {
   producto *= c;
   ++c;
}
  2. if ( genero == 1 )
   document.writeln( "Mujer" );
else;
   document.writeln( "Hombre" );
    Error: el ; después de else es una instrucción vacía. El else "no hace nada" y la segunda salida se ejecuta siempre (error lógico).
    Corrección: quitar el punto y coma. 
    if ( genero == 1 )
   document.writeln( "Mujer" );
else
   document.writeln( "Hombre" );
