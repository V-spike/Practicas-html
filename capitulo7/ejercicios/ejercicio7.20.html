Ejercicio 7.20

Determinar si un número de cinco dígitos es palíndromo

Un palíndromo se lee igual al derecho y al revés (12321, 55555, 45554, 11611). Si el número no tiene 5 dígitos, se muestra un alert y se vuelve a pedir.

¿Cómo se separan los dígitos?

Con división y residuo. Para 12321:

  • % 10 se queda con el último dígito: 12321 % 10 = 1
  • Dividir entre 10 y quitar decimales "recorre" el número: parseInt( 12321 / 10 ) = 1232
  • Combinando ambas: parseInt( n / 1000 ) % 10 = 12 % 10 = 2 (el segundo dígito)

Pseudocódigo

valido = falso
Mientras valido sea falso
    Pedir un número
    Si número >= 10000 y número <= 99999   (dos if anidados)
        valido = verdadero
    Si no
        Mostrar alert "Debe tener 5 dígitos"
Obtener d1, d2, d4, d5 (el dígito central d3 no importa)
Si d1 es igual a d5
    Si d2 es igual a d4
        Mostrar "Es palíndromo"
    Si no
        Mostrar "No es palíndromo"
Si no
    Mostrar "No es palíndromo"

Resultado

Datos de prueba sugeridos: 12321 y 45554 (sí son); 12345 (no es); 123 y 999999 (deben mostrar el alert).
