Ejercicio 7.04

Escriba una instrucción en JavaScript para realizar cada una de las siguientes tareas

  1. Declarar las variables suma y x. 
    var suma, x;
  2. Asignar 1 a la variable x. 
    x = 1;
  3. Asignar 0 a la variable suma. 
    suma = 0;
  4. Sumar la variable x a suma y asignar el resultado a suma. 
    suma += x;   // o bien: suma = suma + x;
  5. Imprimir "La suma es: " seguido del valor de suma. 
    document.writeln( "La suma es: " + suma );

Nota: la respuesta del libro escribe "La suma es: ", + suma con una coma. Es un error de impresión: lo correcto es concatenar con +.
