Ejercicio 7.13

Ingresos semanales de un vendedor por comisión

El vendedor gana $200 por semana más el 9% de sus ventas brutas. Valores de los artículos:

ArtículoValor
1239.99
2129.75
399.95
4350.89

Se pide cada artículo vendido (1 a 4) con prompt; el centinela 0 termina. Como switch se ve en el capítulo 8, el precio se elige con if...else anidados.

Pseudocódigo

Inicializar ventas en 0
Pedir el número de artículo (0 para terminar)
Mientras artículo sea distinto de 0
    Si artículo es 1, sumar 239.99 a ventas
    Si no, si artículo es 2, sumar 129.75 a ventas
    Si no, si artículo es 3, sumar 99.95 a ventas
    Si no, si artículo es 4, sumar 350.89 a ventas
    Si no, mostrar "Artículo no válido"
    Pedir el siguiente número de artículo
ingresos = 200 + 0.09 * ventas
Mostrar ventas e ingresos

Resultados

Datos de prueba sugeridos: artículos 1, 2, 4 y luego 0. Ventas = 720.63, ingresos = $264.86.
