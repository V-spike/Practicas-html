Ejercicio 7.08

¿Qué está mal en la siguiente instrucción while?

while ( z >= 0 )
   suma += z;

Respuesta: el valor de z nunca cambia dentro del cuerpo del while. Si la condición z >= 0 es verdadera al principio, lo será siempre y se crea un ciclo infinito.

Corrección: decrementar z para que en algún momento sea menor que 0 (y usar llaves, porque ahora el cuerpo tiene dos instrucciones): 

while ( z >= 0 )
{
   suma += z;
   --z;
}
