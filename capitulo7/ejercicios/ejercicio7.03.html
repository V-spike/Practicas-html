Ejercicio 7.03

Escriba instrucciones en JavaScript para realizar cada una de las siguientes tareas

  1. Asignar la suma de x y y a z, e incrementar x en 1 después del cálculo (una sola instrucción). 
    z = x++ + y;
    Se usa postincremento porque primero se usa el valor actual de x y después se incrementa.
  2. Evaluar si cuenta es mayor que 10; de ser así, imprimir "Cuenta es mayor que 10". 
    if ( cuenta > 10 )
   document.writeln( "Cuenta es mayor que 10" );
  3. Decrementar x en 1 y luego restarla a total (una sola instrucción). 
    total -= --x;
    Se usa predecremento porque primero se decrementa x y luego se resta el nuevo valor.
  4. Calcular el residuo de dividir q entre divisor y asignarlo a q (dos maneras). 
    q %= divisor;
q = q % divisor;
