Ejercicio 7.19

Problema del else suelto

El intérprete ignora la sangría y asocia cada else con el if anterior más cercano, a menos que las llaves digan otra cosa. Se analiza con x = 9, y = 11 y con x = 11, y = 9.

a) Sin llaves

Así lo entiende realmente el intérprete (con la sangría correcta):

if ( x < 10 )
   if ( y > 10 )
      document.writeln( "<p>*****</p>" );
   else
      document.writeln( "<p>#####</p>" );
document.writeln( "<p>$$$$$</p>" );   // está fuera de los if: se ejecuta siempre
  • x = 9, y = 11: imprime ***** y $$$$$
  • x = 11, y = 9: imprime solo $$$$$ (el else pertenece al if interno, que ni se evalúa porque x < 10 es falso)

b) Con llaves

if ( x < 10 )
{
   if ( y > 10 )
      document.writeln( "<p>*****</p>" );
}
else
{
   document.writeln( "<p>#####</p>" );
   document.writeln( "<p>$$$$$</p>" );
}
  • x = 9, y = 11: imprime solo *****
  • x = 11, y = 9: imprime ##### y $$$$$ (ahora el else pertenece al if externo)
