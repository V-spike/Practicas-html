Ejercicio 7.11

Kilómetros por litro de cada viaje y total acumulado

Se piden los kilómetros y los litros de cada viaje con prompt. Se muestra el rendimiento (km/L) de cada viaje y el rendimiento total acumulado. Como no se sabe cuántos viajes hay, se usa un centinela: escribir -1 en los kilómetros termina.

Pseudocódigo (refinamiento arriba-abajo)

Cima: Calcular y mostrar el rendimiento de cada viaje y el rendimiento total.

Primer refinamiento:

Inicializar variables
Leer los datos de cada viaje, mostrar su rendimiento y acumular totales
Mostrar el rendimiento total

Segundo refinamiento:

Inicializar totalKilometros en 0
Inicializar totalLitros en 0

Pedir los kilómetros del primer viaje (o -1 para terminar)
Mientras kilómetros sea distinto de -1
    Pedir los litros usados
    Sumar kilómetros a totalKilometros
    Sumar litros a totalLitros
    Mostrar kilómetros / litros de este viaje
    Mostrar totalKilometros / totalLitros hasta este punto
    Pedir los kilómetros del siguiente viaje (o -1 para terminar)

Si totalLitros es distinto de 0
    Mostrar el rendimiento total
Si no
    Mostrar "No se introdujeron viajes"

Resultados

Datos de prueba sugeridos (3 conjuntos): 300 km / 25 L = 12 km/L; 250 km / 20 L = 12.5 km/L; 180 km / 18 L = 10 km/L. El total es 730 / 63 = 11.587... km/L.
