Ejercicio 7.21

Ciclo infinito: múltiplos de 2 (2, 4, 8, 16, 32...)

El libro pide un ciclo que nunca termine. Para que no se congele esta página cada vez que la abras desde el índice, el ciclo solo se ejecuta si aceptas el confirm.

El código del ciclo

var valor = 1;

while ( true )   // la condición siempre es verdadera: el ciclo nunca termina
{
   valor *= 2;
   document.writeln( "<p>" + valor + "</p>" );
}

¿Qué ocurre al ejecutarlo?

  • La pestaña se congela: JavaScript nunca termina, así que el navegador no puede terminar de dibujar la página ni responder a clics. Normalmente no alcanzas a ver ningún número.
  • Después de unos segundos el navegador muestra un aviso de "La página no responde" con la opción de cerrarla.
  • Si pudieras ver los valores, crecerían hasta 21023 (unas 1023 vueltas) y después se mostraría Infinity para siempre, porque el número ya no cabe en memoria.
  • Además, la memoria de la pestaña crece sin parar porque cada writeln agrega más texto.

Para salir: cierra la pestaña o usa el botón del aviso. Si no responde, abre el Administrador de tareas del navegador con Shift + Esc (en Chrome o Edge) y finaliza el proceso de esa pestaña.
