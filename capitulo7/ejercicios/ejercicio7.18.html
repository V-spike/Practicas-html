Ejercicio 7.18

Sin ejecutarla, determine lo que imprime la secuencia de comandos

var fila = 10;
var columna;

while ( fila >= 1 )
{
   columna = 1;
   document.writeln( "<p>" );

   while ( columna <= 10 )
   {
      document.write( fila % 2 == 1 ? "<" : ">" );
      ++columna;
   } // end while

   --fila;
   document.writeln( "</p>" );
} // end while

Análisis (prueba de escritorio)

  • El ciclo externo recorre fila de 10 hasta 1, así que hay 10 párrafos.
  • El ciclo interno se repite 10 veces por fila, así que cada párrafo tiene 10 símbolos.
  • fila % 2 == 1 es verdadero cuando la fila es impar. Las filas impares imprimen < y las pares imprimen >.
  • Como empieza en 10 (par), la primera línea es de > y luego se alternan.

Salida esperada:

>>>>>>>>>>   (fila 10)
<<<<<<<<<<   (fila 9)
>>>>>>>>>>   (fila 8)
<<<<<<<<<<   (fila 7)
>>>>>>>>>>   (fila 6)
<<<<<<<<<<   (fila 5)
>>>>>>>>>>   (fila 4)
<<<<<<<<<<   (fila 3)
>>>>>>>>>>   (fila 2)
<<<<<<<<<<   (fila 1)
