Ejercicio 7.09

Identifique y corrija los errores en cada segmento de código

  1. if ( edad >= 65 );
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65 )";
    Errores:
    1. El ; después del if termina la instrucción ahí. Entonces el else queda "suelto" sin un if y es un error de sintaxis.
    2. En el último writeln la comilla de cierre está después del paréntesis: 65 )";. Debe ser 65" );.
    Corrección: 
    if ( edad >= 65 )
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65" );
  2. var x = 1, total;
while ( x <= 10 )
{
   total += x;
   ++x;
}
    Error: total nunca se inicializa. Vale undefined, y undefined + 1 da NaN, así que el resultado final es NaN.
    Corrección: 
    var x = 1, total = 0;
  3. var x = 1;
var total = 0;
while ( x <= 100 )
   total += x;
   ++x;
    Error: sin llaves, el while solo controla total += x;. La sangría engaña: ++x nunca se ejecuta dentro del ciclo, así que x se queda en 1 y el ciclo es infinito.
    Corrección: 
    while ( x <= 100 )
{
   total += x;
   ++x;
}
  4. var y = 5;
while ( y > 0 )
{
   document.writeln( y );
   ++y;
    Errores:
    1. ++y hace que y crezca (6, 7, 8...). Nunca llega a ser 0, por lo que el ciclo es infinito. Debe ser --y.
    2. Falta la llave } que cierra el cuerpo del while.
    Corrección: 
    var y = 5;
while ( y > 0 )
{
   document.writeln( y );
   --y;
}
