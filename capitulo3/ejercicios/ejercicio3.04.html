Ejercicio 3.04 - Complete las siguientes oraciones

a Falso. Los navegadores que despliegan input color como campo de texto requieren un código hexadecimal y no el nombre de un color.

b Verdadero. Al enviar un formulario, HTML5 verifica automáticamente los datos mediante sus mecanismos de validación.

c Falso. HTML5 valida el formato de una dirección de correo electrónico, pero no verifica si existe realmente.

d Verdadero. El atributo required puede utilizarse para indicar que un campo es obligatorio.

e Verdadero. El atributo autocomplete puede habilitarse para ciertos elementos input.

f Verdadero. El elemento time permite identificar una fecha, una hora o ambas.

g Falso. La leyenda de una imagen en un elemento figure se proporciona mediante el elemento figcaption.

h Falso. El elemento summary muestra la flecha y el resumen; al hacer clic revela el contenido del elemento details.

i Verdadero. El elemento footer describe el contenido que generalmente aparece en la parte inferior de una página o sección.

j Falso. No existe el elemento highlight; para resaltar texto se utiliza el elemento mark.
