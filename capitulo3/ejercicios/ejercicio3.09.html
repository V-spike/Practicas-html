Sección 3.2.1

HTML5 es un lenguaje utilizado para crear y estructurar el contenido de las páginas Web. Sus elementos permiten organizar información, agregar formularios, imágenes, enlaces y diferentes tipos de contenido multimedia. Además, HTML5 incorpora elementos semánticos que ayudan a definir con mayor claridad la estructura de una página.
