Ejercicio 8.04

Encuentre el error en cada segmento de código (puede haber más de uno)

  1. For ( x = 100, x >= 1, ++x )
   document.writeln( x );
    Errores:
    1. For con mayúscula no existe: JavaScript distingue mayúsculas. Es for.
    2. Las partes del encabezado se separan con punto y coma, no con comas.
    3. Si se cuenta de 100 hacia 1, hay que decrementar. Con ++x, x crece para siempre (ciclo infinito).
    Corrección: 
    for ( x = 100; x >= 1; --x )
   document.writeln( x );
  2. Debe imprimir si el entero es par o impar: 
    switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
   case 1:
      document.writeln( "Entero impar" );
}
    Error: falta break en el case 0. Con un número par se imprime "Entero par" y "Entero impar".
    Corrección: 
    switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
      break;
   case 1:
      document.writeln( "Entero impar" );
}
  3. Debe imprimir los impares del 19 al 1: 
    for ( x = 19; x >= 1; x += 2 )
   document.writeln( x );
    Error: x += 2 sube (19, 21, 23...) y la condición x >= 1 nunca se vuelve falsa, así que el ciclo es infinito.
    Corrección: x -= 2.
  4. Debe imprimir los pares del 2 al 100: 
    contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} While ( contador < 100 );
    Errores:
    1. While con mayúscula: debe ser while.
    2. Con < 100 el 100 no se imprime. Debe ser <= 100.
    Corrección: 
    contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} while ( contador <= 100 );
