Ejercicio 8.11

Ventas de un vendedor minorista en línea

ProductoPrecio
1$2.98
2$4.50
3$9.98
4$4.49
5$6.87

Se leen pares (número de producto, cantidad vendida). El switch elige el precio y el centinela 0 en el número de producto termina. Compáralo con el ejercicio 7.13, donde lo mismo se hizo con if...else if.

Pseudocódigo

total = 0
Pedir número de producto (0 para terminar)
Mientras producto sea distinto de 0
    Según producto, asignar precio (switch)
    Si el producto es válido
        Pedir cantidad
        total += precio * cantidad
    Pedir número de producto
Mostrar total

Resultado

Datos de prueba sugeridos: producto 1, cantidad 10 ($29.80); producto 3, cantidad 2 ($19.96); producto 5, cantidad 4 ($27.48); luego 0. El total es $77.24.
