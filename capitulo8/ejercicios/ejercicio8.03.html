Ejercicio 8.03

Encuentre el error en cada segmento de código y explique cómo corregirlo

  1. x = 1;
while ( x <= 10 );
   ++x;
}
    Error: el punto y coma después del encabezado del while lo deja con un cuerpo vacío. x nunca cambia y se crea un ciclo infinito. Además falta la llave izquierda {.
    Corrección: reemplazar el ; por {. 
    x = 1;
while ( x <= 10 ) {
   ++x;
}
  2. switch ( n )
{
   case 1:
      document.writeln( "El n&uacute;mero es 1" );
   case 2:
      document.writeln( "El n&uacute;mero es 2" );
      break;
   default:
      document.writeln( "El n&uacute;mero no es 1 ni 2" );
      break;
}
    Error: falta break en el case 1. Si n vale 1 se imprime "El número es 1" y también "El número es 2", porque la ejecución "cae" al siguiente caso.
    Corrección: agregar break; al final del case 1. (No sería error si de verdad se quisiera ejecutar las dos cosas.)
  3. Debe imprimir los valores del 1 al 10: 
    n = 1;
while ( n < 10 )
   document.writeln( n++ );
    Error: el operador relacional es incorrecto. Con < solo imprime del 1 al 9 (error por desplazamiento en uno).
    Corrección: usar n <= 10, o bien n < 11.
