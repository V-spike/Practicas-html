Ejercicio 8.02

Escriba instrucciones en JavaScript para realizar cada tarea

  1. Sumar los enteros impares entre 1 y 99 con una instrucción for. 
    suma = 0;
for ( cuenta = 1; cuenta <= 99; cuenta += 2 )
   suma += cuenta;
  2. Calcular 2.5 elevado a la potencia 3 con el método pow. 
    Math.pow( 2.5, 3 )
  3. Imprimir los enteros del 1 al 20 con while y la variable x, cinco por línea. 
    x = 1;
document.writeln( "<p>" );
while ( x <= 20 ) {
   document.write( x + " " );
   if ( x % 5 == 0 )
      document.write( "</p><p>" );
   ++x;
}
document.writeln( "</p>" );
  4. Lo mismo que c), pero con for. 
    document.writeln( "<p>" );
for ( x = 1; x <= 20; x++ ) {
   document.write( x + " " );
   if ( x % 5 == 0 )
      document.write( "</p><p>" );
}
document.writeln( "</p>" );
