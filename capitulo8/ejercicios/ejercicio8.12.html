Ejercicio 8.12

Suponga que i = 1, j = 2, k = 3 y m = 2. ¿Qué imprime cada instrucción?

InstrucciónEvaluaciónImprime
a)i == 11 == 1true
b)j == 32 == 3false
c)i >= 1 && j < 4true && truetrue
d)m <= 99 && k < mtrue && (3 < 2 = false)false
e)j >= i || k == mtrue || ... (corto circuito: ya no evalúa k == m)true
f)k + m < j || 3 - j >= k(5 < 2 = false) || (1 >= 3 = false)false
g)!( k > m )!( 3 > 2 ) = !truefalse

¿Son necesarios los paréntesis?

  • a) a f): no. Por precedencia, la aritmética (+ -) va antes que los relacionales (< >=), estos antes que la igualdad (==), luego && y al final ||. La expresión se agrupa sola de forma correcta.
  • g): sí. El operador ! tiene mayor precedencia que >. Sin paréntesis, !k > m significaría (!k) > m, es decir, false > 2. Aquí da el mismo resultado de casualidad, pero significa otra cosa.

Comprobación (ejecución real)

Ojo: en la comprobación cada expresión va entre paréntesis porque se concatena con "<p>a) " + .... Sin ellos, el + se evaluaría primero (tiene mayor precedencia que ==) y compararía el texto completo.
