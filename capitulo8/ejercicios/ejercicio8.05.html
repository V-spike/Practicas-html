Ejercicio 8.05

¿Qué es lo que hace el siguiente programa?

document.writeln( "<table>" );

for ( var i = 1; i <= 10; i++ )
{
   document.writeln( "<tr>" );

   for ( var j = 1; j <= 5; j++ )
      document.writeln( "<td>(" + i + ", " + j + ")</td>" );

   document.writeln( "</tr>" );
} // fin de for

document.writeln( "</table>" );

Respuesta

Crea una tabla de 10 filas por 5 columnas. Hay dos for anidados:

  • El externo (i de 1 a 10) crea cada fila <tr>.
  • El interno (j de 1 a 5) crea las 5 celdas de esa fila.
  • Cada celda muestra sus "coordenadas" (fila, columna): la primera fila es (1, 1) (1, 2) ... (1, 5) y la última es (10, 1) ... (10, 5).

En total se ejecuta el writeln de las celdas 10 × 5 = 50 veces. Nota: el libro termina con <body />, que no es válido en HTML5; lo correcto es <body></body>.
