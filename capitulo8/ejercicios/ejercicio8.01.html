Ejercicio 8.01

Indique si cada enunciado es verdadero o falso. Si es falso, explique por qué

  1. El caso default es requerido en la instrucción de selección switch.
    Falso. El caso default es opcional. Si no se necesita una acción predeterminada, no hace falta.
  2. La instrucción break es requerida en el último caso de una instrucción switch.
    Falso. break sirve para salir del switch. En el último caso no hace falta, porque después ya no hay más casos y el control sigue con la instrucción que va después del switch.
  3. La expresión ( x > y && a < b ) es verdadera si x > y es verdadera, o si a < b es verdadera.
    Falso. Con && ambas condiciones deben ser verdaderas. Lo que describe el enunciado ("una u otra") es el operador ||.
  4. Una expresión que contiene el operador || es verdadera si uno o ambos de sus operandos son verdaderos.
    Verdadero.
