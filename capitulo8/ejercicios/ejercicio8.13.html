Ejercicio 8.13

¿Qué valores se asignan a x cuando k vale 1, 2, 3, 4 y 10?

switch ( k )
{
   case 1:
      break;
   case 2:
   case 3:
      ++k;
      break;
   case 4:
      --k;
      break;
   default:
      k *= 3;
} //fin de switch

x = k;

Análisis

k inicial¿Qué pasa?x
1case 1: solo hay break, k no cambia1
2case 2 no tiene instrucciones y "cae" al case 3: ++k3
3case 3: ++k4
4case 4: --k3
10Ningún case coincide, entra al default: k *= 330

Los casos 2 y 3 juntos son un ejemplo de "varias etiquetas case para la misma acción".
