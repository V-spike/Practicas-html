Ejercicio 9.30

¿Qué hace la siguiente función?

// El parámetro b debe ser entero
// positivo para evitar recursividad infinita
function misterio( a, b )
{
   if ( b == 1 )
      return a;
   else
      return a + misterio( a, b - 1 );
}

Respuesta

Multiplica a × b con sumas repetidas: suma a consigo mismo b veces. Ejemplo con misterio( 4, 3 ): 

misterio( 4, 3 ) = 4 + misterio( 4, 2 )
                 = 4 + ( 4 + misterio( 4, 1 ) )
                 = 4 + ( 4 + 4 )        ← caso base: b == 1 devuelve a
                 = 12

Si b fuera 0 o negativo, nunca llegaría a 1 y la recursividad sería infinita (Error común 9.3).
