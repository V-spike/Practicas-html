Ejercicio 9.02

Indique el alcance (global o de función) de cada elemento del programa de la figura 9.13

var x;

function salida()
{
   for ( x = 1; x <= 10; x++ )
      document.writeln( "<p>" + cubo( x ) + "</p>" );
} // fin de la función salida

function cubo( y )
{
   return y * y * y;
} // fin de la función cubo

window.addEventListener( "load", salida, false );
  1. La variable x: alcance global. Se declara con var fuera de cualquier función. Ojo: salida no la declara, solo la usa, así que trabaja con la global.
  2. La variable y: alcance de función. Es un parámetro de cubo, y los parámetros son variables locales.
  3. La función cubo: alcance global.
  4. La función salida: alcance global.

Ejecución (figura 9.13)

Imprime los cubos del 1 al 10. Como salida se llama con el evento load, usa document.writeln después de cargar la página y reemplaza todo el documento. Por eso aquí se muestra en un div con innerHTML.
