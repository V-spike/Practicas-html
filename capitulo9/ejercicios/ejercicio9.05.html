Ejercicio 9.05

Localice el error en cada segmento de programa y explique cómo corregirlo

  1. method g()
{
   document.writeln( "Dentro del m&eacute;todo g" );
}
    Error: method no es una palabra clave de JavaScript. Las funciones se definen con function.
    Corrección: function g() 
  2. // Esta función debe devolver la suma de sus argumentos
function suma( x, y )
{
   var resultado;
   resultado = x + y;
}
    Error: calcula la suma pero no la devuelve, así que quien la llame recibe undefined. Es un error lógico (Error común de programación 9.1).
    Corrección: agregar return resultado; al final, o simplificar todo a return x + y; 
  3. function f( a );
{
   document.writeln( a );
}
    Error: el punto y coma después del paréntesis de la lista de parámetros. En la copia escaneada del libro no se alcanza a ver, pero la respuesta del libro confirma que ese es el error.
    Corrección: quitar el ; que va después de f( a ).
