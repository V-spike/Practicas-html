Ejercicio 9.11

Enteros aleatorios en distintos rangos

Fórmula general: n = Math.floor( a + Math.random() * b ), donde a es el primer número del rango y b es la cantidad de enteros del rango (último − primero + 1).

RangoabInstrucción
a)1 ≤ n ≤ 212n = Math.floor( 1 + Math.random() * 2 );
b)1 ≤ n ≤ 1001100n = Math.floor( 1 + Math.random() * 100 );
c)0 ≤ n ≤ 9010n = Math.floor( Math.random() * 10 );
d)1000 ≤ n ≤ 11121000113n = Math.floor( 1000 + Math.random() * 113 );
e)−1 ≤ n ≤ 1−13n = Math.floor( -1 + Math.random() * 3 );
f)−3 ≤ n ≤ 11−315n = Math.floor( -3 + Math.random() * 15 );

Comprobación: 1000 valores de cada rango (mínimo y máximo obtenidos)
