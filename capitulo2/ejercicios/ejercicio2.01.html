Ejercicio 2.1

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

a) Una lista ordenada no puede anidarse dentro de una lista desordenada.

Respuesta: Falso.

Una lista ordenada sí puede anidarse dentro de una lista desordenada.

b) El elemento br representa un salto de línea.

Respuesta: Verdadero.

El elemento <br> se utiliza para insertar un salto de línea.

c) Los hipervínculos se denotan mediante el elemento link.

Respuesta: Falso.

Los hipervínculos se crean mediante el elemento <a>, utilizando el atributo href.

d) La anchura de todas las celdas de datos en una tabla debe ser igual.

Respuesta: Falso.

Las celdas de una tabla pueden tener diferentes anchuras.

e) Estamos limitados a un máximo de cinco vínculos internos por página.

Respuesta: Falso.

No existe un límite de cinco vínculos internos por página. Una página puede tener muchos vínculos internos.

Resumen

  1. a) Falso
  2. b) Verdadero
  3. c) Falso
  4. d) Falso
  5. e) Falso
