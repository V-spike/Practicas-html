Ejercicio 2.2

Complete las siguientes oraciones:

a)

El elemento hr inserta una regla horizontal.

b)

Para marcar un superíndice se utiliza el elemento sup.

c)

El elemento de encabezado menos importante es h6.

d)

El elemento ul marca una lista desordenada.

e)

El elemento p marca un párrafo.

f)

Para marcar un subíndice se utiliza el elemento sub.

g)

El elemento de encabezado más importante es h1.

h)

El atributo reset en un elemento input inserta un botón que, cuando se presiona, restablece el contenido del formulario.

i)

El elemento tr marca una fila de una tabla.

j)

Los asteriscos (*) se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.

Respuestas

  1. hr
  2. sup
  3. h6
  4. ul
  5. p
  6. sub
  7. h1
  8. reset
  9. tr
  10. Asteriscos (*)
