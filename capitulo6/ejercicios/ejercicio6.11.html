Ejercicio 6.11

¿Qué aparece en el diálogo de alerta cuando se ejecuta cada una de las siguientes instrucciones? Asuma que x = 2 y y = 3

  1. window.alert("x = " + x);
    Aparece: x = 2
  2. window.alert("El valor de x + x es " + (x + x));
    Aparece: El valor de x + x es 4
    Los paréntesis hacen que x + x se sume primero (da 4) y después ese número se une al texto. Sin ellos, el + uniría el texto con cada 2 por separado y saldría "...es 22".
  3. window.alert("x =");
    Aparece: x =
    Todo está entre comillas, así que es texto fijo y no se usa el valor de ninguna variable.
  4. window.alert((x + y) + " = " + (y + x));
    Aparece: 5 = 5
    Cada paréntesis suma sus dos números (2 + 3 y 3 + 2) y después los resultados se unen con el texto " = ".
