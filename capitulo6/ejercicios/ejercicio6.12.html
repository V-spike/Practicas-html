Ejercicio 6.12

¿Cuál de las siguientes instrucciones de JavaScript contiene variables cuyos valores se modifican?

  1. p = i + j + k + 7;
    Sí. La variable p recibe un valor nuevo. Las variables i, j y k solo se leen.
  2. window.alert("variables cuyos valores se destruyen");
    No. Solo muestra un texto fijo. No hay ninguna variable.
  3. window.alert("a = 5");
    No. El a = 5 está entre comillas, es solo texto. No se asigna nada a ninguna variable.
  4. cadenaVal = window.prompt("Escriba una cadena:");
    Sí. La variable cadenaVal recibe como nuevo valor lo que el usuario escriba.

Respuesta: las instrucciones de los incisos a) y d).
