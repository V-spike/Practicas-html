Ejercicio 6.04

Identifique y corrija los errores en cada una de las siguientes instrucciones

a

Instrucción con error:

if (c < 7);
    window.alert("c es menor que 7");

Error: hay un punto y coma después del paréntesis de la condición. Eso termina el if con una instrucción vacía, así que window.alert se ejecuta siempre, sin importar el valor de c.

Corrección (se elimina el punto y coma):

if (c < 7)
    window.alert("c es menor que 7");

b

Instrucción con error:

if (c => 7)
    window.alert("c es igual o mayor que 7");

Error: => no es un operador relacional válido en una condición. El operador de "mayor o igual que" se escribe con el > primero y el = después.

Corrección (se cambia => por >=):

if (c >= 7)
    window.alert("c es igual o mayor que 7");
