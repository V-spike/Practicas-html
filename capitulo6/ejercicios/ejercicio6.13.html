Ejercicio 6.13

Dada y = ax³ + 7, ¿cuáles de las siguientes instrucciones de JavaScript son correctas para esta ecuación?

  1. y = a * x * x * x + 7;
    Correcta. Calcula a·x·x·x (es decir, ax³) y después suma 7.
  2. y = a * x * x * (x + 7);
    Incorrecta. El paréntesis hace que se multiplique por (x + 7), lo que da ax³ + 7ax², no ax³ + 7.
  3. y = (a * x) * x * (x + 7);
    Incorrecta. Mismo problema que en el inciso b: el 7 queda multiplicado por ax².
  4. y = (a * x) * x * x + 7;
    Correcta. Los paréntesis son innecesarios, pero no cambian el resultado: la multiplicación se evalúa antes que la suma, y da ax³ + 7.

Respuesta: las instrucciones de los incisos a) y d).
